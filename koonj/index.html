From active storage to archive and back

  1. Discover

    Scan registered storage and build a searchable inventory so your team can see what’s there before deciding what to move.

  2. Archive and tier

    Archive files to a registered Amazon S3 bucket. Tier files on managed storage to free up working space while keeping a path to recall.

  3. Recall

    Restore files or folders when you need them. With the Linux gateway configured, users can open archived files from familiar file managers.

Control across your storage estate

Bring storage into view

Register local directories and host-mounted NAS or SMB shares. Verify Amazon S3 bucket access and test configured S3-compatible endpoints from the console.

Recall from familiar tools

With the gateway and SMB configured, users can request archived files from Windows Explorer, macOS Finder, and Linux file managers. Cold storage may need time to restore an object before it becomes available.

Run transfers in parallel

Archive and recall can run concurrently on separate paths. Transfer workers can scale independently, and Koonj reserves affected paths to prevent overlapping jobs from interfering.

Track what moves

Monitor scan and transfer progress, review activity in the audit log, and pause or retry transfers when needed. Koonj uses checksums to verify transferred files.
