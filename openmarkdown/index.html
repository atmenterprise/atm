Live file sync

Your agent edits the file. You watch it change.

Open a local file in Chrome or Edge and it stays linked to the copy on your computer. When an agent or a terminal command changes that file, the editor updates within half a second. Your cursor, scroll position and undo history stay where they were.

  • Have unsaved changes? You choose whether to reload or keep your version.
  • Press ⌘S or Ctrl+S to save straight back to the file.
  • Open files with the file picker, by dragging them in, or with Open with → OpenMarkdown.
Get started

Three steps to an agent-ready editor.

You need desktop Chrome or Edge and Node.js 20.19 or newer. It’s free and you don’t need an account.

  1. 1

    Install it on your desktop

    Open the editor in Chrome or Edge and click the install icon in the address bar (or Menu → Install OpenMarkdown). It opens in its own window and appears under Open with for .md files in Finder, File Explorer and Linux file managers.

    Desktop setup guide
  2. 2

    Add the MCP server

    Run one command. Your agent then starts @appsthatmatter/openmarkdown-mcp with npx when it needs it.

    claude mcp add --transport stdio openmarkdown -- npx -y @appsthatmatter/openmarkdown-mcp
  3. 3

    Connect and go

    Ask your agent to “open this in openMarkdown” and it opens a connected window for you. Or click Agent bridge in the editor’s top bar or footer, then Turn on.

    When the status bar shows MCP Connected, you’re ready. If your browser asks to allow access to apps on this device, choose Allow.

Private by default

Your agent connects to your editor. Nothing else can.

  • Stays on your computer. The bridge only accepts connections from your own machine (127.0.0.1), so nothing on your network or the internet can reach it.
  • Only OpenMarkdown can connect. Connections from any other website are refused.
  • Off until you turn it on. The editor makes no connection attempts until you enable the bridge or your agent opens it for you.
  • Open source. Licensed under Apache 2.0, so you can read every line on GitHub.

When the bridge is on, your document is shared with the agent you run, which may send it to its AI provider under that provider’s terms.
