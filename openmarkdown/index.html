OpenMarkdown

Write, format, and share Markdown.

Use the formatting toolbar to style your document, see it update live, then download a copy or share it with a link.

Open the editor Desktop setup
Free and open source No account required

From draft to delivery

Format as you write

Add headings, emphasis, checklists, links, and tables from the toolbar in Editor and Split views. Split view shows the formatted result as you edit.

Download in five formats

Save your work as Markdown, plain text, PDF, Word (.docx), or HTML. Formatted exports carry over document structure such as headings, lists, and tables.

Share a read-only link

Send a snapshot anyone with the link can open without an account. The share dialog warns against sharing confidential information because links can be forwarded.

Open Markdown from your desktop

Install OpenMarkdown in desktop Chrome or Edge, then open .md and .markdown files from your file manager on Windows, macOS, or supported Linux desktops.

Open a file from Finder or File Explorer

After installing the web app, right-click a Markdown file and choose Open with → OpenMarkdown. The file opens locally in Preview, with Editor and Split available when you want to make changes.

Use desktop Chrome or Microsoft Edge for file associations. In Safari, you can drag the file into the editor or use Upload files.
