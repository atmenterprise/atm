## LinkedIn (founder's profile)

```text
Stop pasting your writing into a chat window. OpenMarkdown by Apps That Matter is out today: a free Markdown editor your AI agent can work in.

Copy text into the chat, wait, paste the answer back, then check nothing else changed. That loop is how most of us write with AI agents today, and it's the loop I wanted to remove.

OpenMarkdown runs in your browser, and Claude Code, Codex and Cursor can work in it alongside you. Highlight a paragraph, ask your agent to improve it, and watch the change appear in your document.

What's in the first release:

🎯 Your agent sees your selection: which file, which words, which line.
↩️ Every agent edit can be undone with ⌘Z or Ctrl+Z.
✅ You have the final say. Agent edits stay unsaved until you've reviewed them.
🔄 Live file sync. When an agent changes a local file, the editor updates within half a second.
📄 Export to Markdown, plain text, PDF, Word or HTML.
🔒 Private by design. It runs in your browser, and the agent bridge only accepts connections from your own computer.

Connecting your agent takes one command. It's free, open source (Apache 2.0) and needs no account.

👉 https://www.appsthatmatter.uk/openmarkdown/

It's a first release, so feedback shapes what comes next. What would you write with your agent in OpenMarkdown?

#OpenMarkdown #AIAgents #Markdown #ClaudeCode #OpenSource #DeveloperTools
```

**Posting tips**
- Attach `one-pager-portrait.png` (1080×1350), or upload the 49-second demo video (`public/openmarkdown/videos/openmarkdown-demo.mp4`), which has captions and no sound.
- For more reach, take the 👉 link line out of the post and put it in the first comment instead: "Try it here 👉 https://www.appsthatmatter.uk/openmarkdown/".
- If posting from the company page, change "I wanted" to "we wanted".
